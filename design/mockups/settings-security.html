Как мы храним API-ключи и обрабатываем отчёты селлеров

API-ключи маркетплейсов

  • Шифрование at rest (AES-256) · доступ только сервису аналитики
  • Серверы в РФ · соответствие 152-ФЗ
  • Минимальные scope: только статистика, без write-методов
  • Отзыв ключа в umetrica = немедленная остановка синхронизации
  • Все обращения к API пишутся в audit log (Enterprise)

Как создать ключ WB с минимальными правами

  1. Кабинет продавца → Настройки → Доступ к API
  2. Создайте ключ «Только статистика» / read-only
  3. Не включайте контент, цены, рекламу и финансы
  4. Вставьте ключ здесь или в подключении

Загруженные файлы
